# TradeFlow - ADR Future Register

- Accounting connector implementations
- Tax/trade-system connector implementations
- Payment gateways
- Logistics/SMS/email integrations
- Event/webhook ecosystem

## 2. Advanced Commercial Capabilities
- Multi-currency
- Advanced tax engine
- Cost and margin domain
- Advanced pricing engine
- Customer/supplier portals
- Subscription and plan enforcement

## 3. Advanced Operations
- Full offline synchronization and conflict resolution
- Advanced inventory/ATP extensions
- Global search at scale
- Bulk import/export pipelines
- Advanced exception/SLA automation

## 4. Automation and Intelligence
- OCR
- Geolocation
- Advanced automation
- AI-assisted workflows

## 5. Production Infrastructure
- Advanced observability
- Disaster recovery automation
- Data archival at scale
- Feature-flag platform

## Governance

A future capability moves into the implementation roadmap only after its dependencies, data model, security impact, API impact and operational cost are reviewed.
